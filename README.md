# Empório da Música — Customer Service Agent

Prototype of a text-based customer service agent for Empório da Música, a fictional musical instrument store in Campo Grande/MS, Brazil.

> 🚧 Work in progress.

## How to run

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # Linux/macOS
pip install -r requirements.txt
cp .env.example .env            # optional: the API key can also be entered in the UI
```

## Project structure

```text
data/        data provided by the store (CSVs and policy manual)
src/emporio  agent package
tests/       automated tests
```
